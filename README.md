# Navfaz website — static affiliate-ready foundation

A responsive, lightweight static website for Cloudflare Pages. It is designed for useful calculators, browser tools, guides and carefully verified affiliate links.

## Deploy to Cloudflare Pages
- Framework preset: **None**
- Build command: leave blank
- Build output directory: `/` (the repository root)
- No API keys, database or server are required for the current site.

## Important before launch
- This is a starter implementation, not a claim that every route is already fully implemented.
- Affiliate links are intentionally not fabricated. Add links only after joining a programme, verifying the destination and reviewing its rules.
- The newsletter form is a front-end demo and does not collect or send emails.
- Review privacy, terms and affiliate disclosure for your actual business and jurisdiction.
- Run through every link and calculator before switching the custom domain.

## Project structure
- `index.html`: homepage
- `css/styles.css`: design tokens and responsive styling
- `js/main.js`: mobile navigation, homepage demo calculator and search
- `calculators/`: calculator pages
- `tools/`: local productivity tools
- `guides/`: editorial buying guides
- `products/`: affiliate/product section starter
- `ai-hub/`: AI resource directory starter
- `about.html`, `contact.html`, `privacy.html`, `terms.html`, `affiliate-disclosure.html`: supporting pages
- `robots.txt`, `sitemap.xml`: basic crawl files
